# Практична робота №1: Блог/CMS для статей.

**Варіант 3:** Блог/CMS для статей.

## Мета роботи

Ознайомитися з базовим синтаксисом мови програмування PHP, навчитися працювати зі змінними, масивами, умовними конструкціями, циклами та функціями, а також поєднувати PHP-код з HTML-розміткою для формування динамічної вебсторінки.

## Про проєкт

Розроблено просту вебсторінку блогу/CMS для відображення інформації про статті. Дані про статті зберігаються у PHP у вигляді масиву асоціативних масивів.

Для кожної статті зберігаються такі дані:

* назва статті (`title`);
* автор (`author`);
* дата публікації (`publishedAt`);
* кількість переглядів (`views`).

PHP використовується для обробки цих даних та їх динамічного виведення у HTML-таблицю.

## Основний функціонал

* **Зберігання даних:** інформація про 6 статей представлена у вигляді масиву асоціативних масивів.
* **Форматування даних:** для формування короткого опису статті використовується типізована функція `formatArticle()`.
* **Умовна логіка:** залежно від кількості переглядів статті автоматично визначається її статус. Якщо кількість переглядів більша за 100, встановлюється статус «Популярна», в іншому випадку — «Звичайна».
* **Виведення даних:** за допомогою циклу `foreach` усі статті виводяться у HTML-таблицю.
* **Агрегація даних:** за допомогою циклу обчислюється сумарна кількість переглядів усіх статей.
* **Формування вебсторінки:** PHP-логіка поєднується з HTML-розміткою, а зовнішній вигляд сторінки задається за допомогою CSS.

## Структура проєкту

Проєкт складається з двох основних файлів:

* `prt.php` — головний PHP-файл, який містить масив статей, функцію форматування, умовну логіку, підрахунок загальної кількості переглядів та HTML-розмітку сторінки.
* `st.css` — файл каскадних таблиць стилів, який використовується для оформлення сторінки, таблиці, заголовків та блоку зі статистикою.

## Результат роботи

У результаті виконання PHP-скрипта у браузері формується вебсторінка блогу. На сторінці відображається таблиця з назвами статей, авторами, датами публікації, кількістю переглядів та автоматично визначеним статусом.

Також у нижній частині сторінки відображається загальна кількість переглядів усіх статей.

## Як запустити локально

1. Відкрити термінал у директорії проєкту.
2. Запустити вбудований PHP-сервер командою:

```bash
php -S localhost:8000
```

3. Відкрити браузер.
4. Перейти за адресою:

```text
http://localhost:8000/prt.php
```

5. Перевірити правильність відображення статей, їх статусів та загальної кількості переглядів.
